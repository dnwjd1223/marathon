# Marathon Atlas

세계 56개 마라톤의 개최 도시와 대회 정보, 신청 일정을 지도에서 확인하는 HTML·CSS·JavaScript 앱입니다.

[현재 서비스](https://marathon-atlas-ict-2026.workspace-642979.chatgpt.site/)

## 실행

저장소를 내려받은 뒤 `dist/index.html`을 브라우저로 열면 됩니다. 설치·빌드·API 키·서버가 필요 없습니다. 지도와 대회 데이터는 로컬 파일이며, 대회 사진과 외부 글꼴은 인터넷 연결이 필요합니다.

## 기능

- 세계지도 도시·숫자 묶음을 클릭하면 대회 정보 팝업
- 묶음 팝업 상단에서 대회 전환
- 대륙·종목·도시·대회명 검색
- 지도 아래 왼쪽 신청 일정, 오른쪽 가까운 대회 최대 10개 세로 표시
- 기준일부터 14일 이내 신청 시작·마감 일정
- 필터링한 대회 CSV 다운로드와 모바일 화면

## 파일

- `dist/index.html`: 화면 구조
- `dist/style.css`, `dist/layout.css`: 디자인과 반응형 배치
- `dist/app.js`: 지도·검색·팝업·접수 일정 계산
- `dist/data.js`: 56개 대회 및 구조화된 접수 이벤트
- `dist/world.js`: Natural Earth 지도 경계

대회 정보는 `dist/data.js`에서 관리합니다. 접수 날짜는 대회별 `registrationEvents`의 `date`, `type`(start/end), `label`로 관리하며 확정된 날짜만 입력합니다.

## 데이터 기준

정보 기준일은 2026.11.06이며 실시간 갱신되지 않습니다. 날짜 선택기는 오늘(한국 시간)로 시작합니다. 14일 범위는 기준일과 14일 뒤를 모두 포함하며 대회 현지 날짜 단위로 계산합니다. 신청 사이드바는 지도 필터와 독립적으로 전체 대회를 확인합니다.

항공료·체류비는 1인·만원, 인천 출발 왕복 이코노미와 현지 5일·4박 중급 호텔 2인 1실 기준의 계획용 추정 범위입니다. 참가비·자선 모금·대행료·쇼핑은 제외합니다. 사진은 과거 대회 참고이며 출처는 각 대회 팝업에서 확인할 수 있습니다.

지도 경계: [Natural Earth](https://www.naturalearthdata.com/), public domain.
